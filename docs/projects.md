# Projects

Most of my projects are **Minecraft plugins** — built with Paper/Bukkit and Nukkit, designed to run on my server and shared openly on GitHub.

## Minecraft Plugins

### CustomBoss
Configurable boss plugin with timed spawns, custom drops &amp; server-wide broadcasts.

- **Tech**: Java, Paper API
- **Features**: scheduled spawns, boss bars, potion effects, admin commands
- [GitHub](https://github.com/DobeShadow/CustomBoss)

### ItemBank
Item banking system with daily interest, a point shop and storage management.

- **Tech**: Java, Paper API
- **Features**: deposit items, earn points daily, redeem rewards
- [GitHub](https://github.com/DobeShadow/ItemBank)

### TeamPlugin
Lightweight team system with PvP protection, summon and GUI.

- **Tech**: Java, Paper API
- **Features**: teams up to 6 players, member summon, team chat
- [GitHub](https://github.com/DobeShadow/TeamPlugin)

### FreeResidence
Free land-claiming plugin that gives every new player a starter claim.

- **Tech**: Java, Paper API (depends on Residence)
- **Features**: one-time free claim, configurable size &amp; worlds
- [GitHub](https://github.com/DobeShadow/FreeResidence)

### AtPlayer
`@mention` plugin with title alert &amp; sound notification in chat.

- **Tech**: Java, Paper API
- **Features**: mention prefix, title/subtitle alerts, name highlighting
- [GitHub](https://github.com/DobeShadow/AtPlayer)

### BaseMessage
Nukkit BaseMessage utility.

- **Tech**: Java, Nukkit API
- [GitHub](https://github.com/DobeShadow/BaseMessage)
